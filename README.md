# VAROLUŞSAL KRİZ BAHANE ÜRETİCİSİ

## DÜNYANIN EN CİDDİ PROJESİ (DEĞİL)

Bu repository, insanlığın en büyük sorununu çözmek için tasarlanmıştır: **"Neden bugün hiçbir şey yapmadım?"**

Artık "çalışmak istemedim" demek yok. Artık bilimsel, felsefi, varoluşsal ve tamamen saçma bahaneleriniz var.

### Nasıl Çalışır?

```bash
python bahane.py
```

Program sizden yapmadığınız işi sorar. Sonra 3 saniye düşünür (derin düşünce modu). Sonra size öyle bir bahane verir ki, şefiniz bile "haklısın kardeşim, hayatta her şey anlamsız" der.

### Örnek Çıktılar:

- "Kod yazamadım çünkü bugün kuantum çoraplarımın sol teki sağ tekiyle konuşuyordu ve ben arabuluculuk yaptım."
- "Toplantıya girmedim çünkü çay bardağım bana 'sen de bir gün buhar olacaksın' dedi ve ben bunu sindiremedim."
- "E-posta atamadım çünkü klavye tuşlarım varoluşsal kriz geçiriyordu."

## UYARI

Bu proje ciddiye alınırsa gerçek varoluşsal kriz yaratabilir. Sorumluluk kabul etmiyoruz.
